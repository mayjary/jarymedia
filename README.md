# jarymedia (Next.js 14)
1. `npm install && npm run dev`
2. Edit email, phone and copy in the `BRAND`, `SERVICES` and `STEPS` objects at the top of `app/page.js`.
3. The contact form opens the visitor's email app addressed to BRAND.email. Swap `send()` for a Resend/Formspree call if you want server-side delivery.
4. Deploy on Vercel.
